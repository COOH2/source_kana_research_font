このフォントの形は平仮名でもなく漢字でもない，両者の間の字形である．この中間字形の作成にあたり，昭和40 年度「小学校新編新しい書き方—どのように改訂されたか，東書教科書ひらがな活字の改善」の主旨を参考にした．同書では以下のように述べられている．

活字は，読むためのもの，視覚的にとらえやすいものであることを第一とし，また，大部数の印刷に堪えられるという活字本来の制約を受けて作られています．そのため，書く文字とおのずから相違します
が，教科書活字と，書写の教科書の毛筆や硬筆の文字との間に開きがあっては，書写指導の立場からみて，問題だと思います．そこで，このたびの書写教科書の編集と並行して，活字のうちで最も問題のあるひらがな活字の改善を行い，書写の学習・指導上の抵抗となっていた点を除くように努めました．改善にあたっては，「古典かな字鑑」の編者，飯島先生（飯島春敬日展評議員日本書道美術理事長昭和三八年春から監修を委嘱）の多年にわたるかな研究を土台に，古来の仮名の標準的な姿を現代的に生かし，しかも，子どもが手本にできる書きやすさを追求して，度重なる検討を加えました．

中間字形は飯島(1960)「古典かな字鑑」を参考に，古典の仮名字形から平仮名でもなく漢字でもない字形をピックアップし，その字形をフォントデザインアプリ[glyphs](https://glyphsapp.com/)を用いてトレースして，毛筆の筆触をできるだけ硬筆の筆触に修正した．
